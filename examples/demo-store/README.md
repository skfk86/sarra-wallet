# متجر تجريبي — بوابة دفع صُرّة

متجر صغير في ملف واحد (`server.js`) بلا أي مكتبات، يوضح الدورة كاملة:
إنشاء فاتورة ← توجيه العميل لصفحة الدفع ← معرفة أن الدفع تم.

## التشغيل

يحتاج Node.js 18 أو أحدث.

```bash
SARRA_KEY=sk_live_xxxxxxxx node server.js
```

ثم افتح <http://localhost:3000> واشترِ منتجاً.

المفتاح تحصل عليه من تطبيق صُرّة: القائمة ← بوابة الدفع للتجار ← إنشاء مفتاح API.

## الإعدادات (متغيرات البيئة)

| المتغير | الوصف |
|---|---|
| `SARRA_KEY` | إلزامي. مفتاح الـ API. |
| `SARRA_WEBHOOK_SECRET` | سر الإشعار `whsec_…`. بدونه يُرفض أي إشعار، ويعتمد المتجر على الاستعلام. |
| `SARRA_NETWORK` | `bsc` (الافتراضي) أو `tron` أو `polygon` أو `eth`. |
| `PORT` | المنفذ. الافتراضي 3000. |

## كيف يعرف المتجر أن الدفع تم؟

بطريقتين، وكلتاهما في الكود:

1. **الإشعار (Webhook):** صُرّة ترسل `POST /sarra-hook` موقّعاً. يحتاج رابط `https` عاماً، فلا يعمل على `localhost`. ضع الرابط في شاشة بوابة الدفع في التطبيق.
2. **الاستعلام:** صفحة الطلب تسأل الخادم كل 5 ثوانٍ، والخادم يسأل `GET /v1/invoices/{id}`. هذه تعمل على `localhost` بلا إعداد.

## قبل استخدامه في متجر حقيقي

- احفظ الطلبات في قاعدة بيانات؛ هنا تُحفظ في الذاكرة وتضيع عند إعادة التشغيل.
- لا تضع `SARRA_KEY` في كود الواجهة أو في تطبيق الموبايل أبداً.
- سلّم المنتج داخل `markPaid` فقط، وهي مكتوبة بحيث لا تسلّم مرتين.
